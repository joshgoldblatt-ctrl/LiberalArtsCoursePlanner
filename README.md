# LaGuardia Liberal Arts Course Planner (Prototype)

A single-file HTML planner for the Liberal Arts: Social Science & Humanities major at LaGuardia Community College. Students and advisors can plan the Program Core, the Pathways Flexible Core, and the Liberal Arts Electives, and see when one course meets both a major and a general-education requirement and frees elective credits.

Open `index.html` in a browser. No server or install needed. Plans save in the browser and can be exported and imported as JSON.

Developed by Josh Goldblatt using Claude.
