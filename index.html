How the planner works

Rules as stated on the Liberal Arts: Social Science & Humanities program sheet.

The three requirements

  • Program Core. One course from 5 of the 6 categories: Modern Language or Literature, English Literature, Philosophy, Humanities, Social Sciences, History.
  • Pathways Flexible Core. Six courses: one from each of World Cultures & Global Issues (WC), U.S. Experience in Its Diversity (US), Scientific World (SW), Individual & Society (IS), Creative Expression (CE), plus one more from any category.
  • Liberal Arts Electives. Each time a Program Core course also satisfies a Flexible Core category, 3 elective credits are freed, up to 15. Freed credits can be used for any Section I or Section 2 course.

Two ways to build a plan

  • Add courses. Type a course or paste a list of codes. Each course goes to the first open requirement that fits: its Program Core category; otherwise an elective row if freed credits allow; otherwise a Flexible Core row matching its code (or the additional row). A course that fits nowhere is reported and not added. Courses outside these three requirements (ENG101, MAT115, and so on) are not accepted.
  • Pick by row. Use the dropdown in any requirement row. Dropdowns list only courses that fit that row.

What the planner does automatically

  1. When a Program Core course carries a Flexible Core code, the matching Flexible Core row fills in. If that category is already filled, the course goes to the Additional course row instead. If both are full, the course still counts for the major but frees no credits, and the row says so.
  2. Each double-count adds an elective row. If you change a pick and lose a freed credit, any elective you already chose stays on the plan with a warning rather than disappearing.
  3. If you pick a Section I course directly in a Flexible Core row, the planner also fills the matching Program Core category when it is open.
  4. If you fill all six Program Core categories, the sixth course you chose is treated as an elective paid with freed credits. It can fill an open Flexible Core row but frees no credits itself.
  5. An elective with a Flexible Core code fills an open Flexible Core row but frees no further credits.
  6. A course can appear only once in the plan. Cross-listed pairs (ENN193/SSN193, ENG238/HUV238) count as one course.
  7. A filled row is shaded. The ▸ button at the end of a row opens a line that says how the course counts: where it came from, what else it fills, whether it frees credits, and any warnings. The button is teal when there is something to show, gold for a caution, and red for a problem.

Status and term

Each course has a status pill (blank until set) and a term. Click the pill to choose Planned, In Progress, or Completed, or to clear it. Status and term belong to the course, so a course that appears in two rows shows the same values in both and can be edited from either.

Saving, sharing, printing

The plan saves itself in this browser as you work. Use Export plan to download a file you can email to a student or advisor, and Import plan to load one. Print plan produces a clean summary.

Data sources and notes

  • Course lists and Flexible Core codes: program sheet Liberal Arts Soc Sci and Hum Electives (3.26.26).
  • Credits, pre/co-requisites, and Flexible Core designations for courses outside the major: Degree Map Prereq Course List Table (August 2026).
  • Catalog links: Course Link Table (July 2026).
  • Seven program-sheet courses carry no code on the sheet but are designated Flexible Core in the catalog table; the planner uses the catalog designation and says so in the course info popover: ELI101 (WC), HUV150 (WC), HUV270 (US), HUC140 (CE), HUV238 (CE), SSJ101 (US), HUN180 (US).
  • Program-sheet codes HUC150, HUC270, HUC238, HUC240, SSD-BTC105, and SSN-HUN180 appear here under their catalog codes HUV150, HUV270, HUV238, HUV240, BTC105, and HUN180.
  • ENG208 Introduction to Digital Journalism is on the program sheet but not in the catalog table, so it has no credit or prerequisite details.
  • Five catalog placeholder entries used for transfer credit (FCCE1000, FCIS1000, FCSW1000, FCUS1000, FCWG1000) are left out. Use Other course not listed in a Flexible Core row for transfer credit.
